# SCRPRN
Hi! Welcome to our repository!

This repository is dedicated to the release of the code for a novel UAV tracking method named Sparse Convolution Ranked Proposal Regression Network (SCRPRN), proposed in our paper entitled: "Real-Time UAV Object Tracking via Sparse Convolution Ranked Proposal Regression Network without Offline Training",which has been submitted to the journal EXPERT SYSTEMS WITH APPLICATIONS.

The source code and experimental results will be publicly released once the paper is officially accepted.
